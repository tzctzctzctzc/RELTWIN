## 结论分析

**答案竞争是核心贡献。** 相同数据、初始化与更新步数的配对对照中，关系mIoU平均提高 **9.71点**、成对正确率提高 **22.00个百分点**，SpotSound平均提高 **0.92点**。三个seed的相同答案分别从59、47、66对降至1、0、0对，各seed关系mIoU增益的95%音频分组置信区间下界均为正。结果支持：显式比较完整时间戳答案，能够改善根据查询选择正确事件窗口的能力。

**集合学习提供进一步改善。** 相比等步数继续第一阶段，关系mIoU提高 **1.10点**、SpotSound提高 **0.59点**，成对正确率提高 **3.33个百分点**。成对正确率增益95%区间为 **[0.33, 6.33]** 个百分点；两项mIoU增益区间跨零，因此重点强调成对定位质量的改善，不宣称mIoU增益显著。

**JS不是本轮主要提点来源。** 仅加入JS时关系mIoU提高0.66点；已有答案竞争时额外提高0.04点，增益区间均跨零。Rebuttal应以“答案竞争改善查询—窗口绑定”为主线，以三seed结果和集合学习等步数对照作为支撑。
