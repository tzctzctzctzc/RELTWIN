# RelTwin 投稿打磨与受限补实验协议

2026-09-13。分支 `codex/reltwin-paper-polish-20260913`。本轮目标是改进论文的证据链和表述，不是通过测试集调参提高分数。所有不利结果同样保留。不改 main、不覆盖历史结果、不自动推送或投稿。

## 决策与计算预算

已有 50/50 项审稿补强队列已经完成，不重启。其结果支持配对候选学习，但 JS 和 SetPO 分别相对去交换项、等更新步数继续训练的增量区间均跨零。因此两者不能再作为已验证的核心独立创新。

新增训练限定为一个 seed 0 SFT 同环境桥接：与 2026-09-12 的 `no_exchange_seed0` 使用同一服务器、环境、训练脚本、初始 adapter、数据顺序、学习率及 256 个更新步数。唯一方法差异是 `sft` 与包含候选交叉熵的 `rbee`（JS 权重为零）。SFT 仍有相同的关系正样本和普通查询回放。等更新步数不等于等计算量；不同目标的前向次数不同。

桥接队列最多运行 7,200 秒累计任务墙钟时间，预留约一小时给一个外部小型关系诊断；本轮新增单卡实验总预算约三小时，不追加种子或超参搜索。若外部数据缺少可靠答案、授权或来源标识，不为填表强行拼出所谓自然泛化实验。只写清缺口，并完成现有证据版稿件。

## SFT 桥接冻结设置

- 初始模型：迁移工程 `models/audio-flamingo-3-hf` + `models/SpotSound`。
- 数据：`reltwin_esc50_v1/train.json`（1,024 条）、`rehearsal.json`（512 条）；256 步，seed 0，lr 5e-6，replay 权重 0.5，AdamW weight decay 0，梯度裁剪 1.0。
- 不新增数据、不选 checkpoint，不依据输出重试不同配置。
- 主要比较：已有当前环境 `no_exchange_seed0` 减新 `sft_current_seed0`。同时展示历史 SFT 同流程重评，衡量历史训练状态差异，但不把重评分数漂移当作方法提升。
- 评估：关系开发集全部 320 条和 SpotSound 全部 400 条；各 10 条 smoke 独立存储，之后执行全量。保持旧评估源码不变。
- 指标：mIoU、JointPairAcc、Swap error、相同输出率；SpotSound 的 mIoU 和 R1；20,000 次按音频及来源连通组的配对 bootstrap。对比已观察的单一种子，不声称训练种子总体显著性。
- 训练类别／源录音与关系开发集零交集继续校验；关系开发集不是新独立测试，SpotSound 已被观察。
- 冻结代码提交、关键源码、协议、manifest、输入音频、初始权重与既有对照预测的哈希及软件版本。运行中不修改冻结文件。
- 超时或失败保留诊断；部分 adapter 不覆盖。不用减少条数伪装完整结果。

## 论文工作优先级

第一优先：摘要和引言聚焦“声音真实存在，但不回答当前关系查询”的局部窗口绑定问题；明确与 T-CLAP、CompA 等全音频组合匹配、SHINE 等视频难负样本工作的区别。区别是监督单位和任务设置，不是首次提出反转、难负例或对比损失。

第二优先：用完整当前重评结果替换旧 P0 的 pending 和旧数字；把无交换候选学习作为简约主方法，把 JS 与 SetPO 放在对照分析中。增加 SFT 的逆查询同答案现象、严格成对成功和错误去向分析，不将输出变化等同于正确理解。

第三优先：主表保留必要文献对照，但分开公开系统性能和训练机制证据；Clotho 的 official+边界结果不能归给 RelTwin。协议未对齐的 UnAV 不参与公平排名。完整系统比分不归因给边界微调或任何单项损失。

第四优先：交付新版本中英文 Markdown、四页技术内容加至多一页纯参考文献的 PDF 和 Overleaf ZIP；完整证据、控制结果、运行开销及局限单列作者备忘。保留旧稿。通过数值、排版、引用、数据对齐与 Git 检查后再标为可供作者审阅。
