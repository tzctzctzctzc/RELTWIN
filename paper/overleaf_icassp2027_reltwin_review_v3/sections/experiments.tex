\section{Experimental Setup}
\subsection{Adaptation and relation diagnostics}
RelTwin uses 40 ESC-50 categories for 256 training recordings: 1,024 relation queries, 512 query pairs across two templates, and 512 category-only rehearsal queries. Ten other categories form the development split: 40 category pairs, two layouts each, 80 recordings, 320 queries, and 160 query pairs. We verified zero overlap in categories and original source-recording IDs between adaptation and development; this does not concern foundation pretraining. The constructed split served method selection, not external testing.

All runs start from the official SpotSound-A adapter on Audio Flamingo~3, updating 20,185,088 adapter parameters. RBEE uses 256 steps, learning rate $5\!\times\!10^{-6}$, $\lambda=1$, $\beta=0.5$, and $\tau=1$. SetPO continues each matched parent for 64 steps at $2\!\times\!10^{-6}$ with $\lambda=0.5$, exchange weight 1, $\tau_y=0.15$, and $\beta=0.5$; setwise rehearsal occurs every fourth step. Seeds are 0, 1, and 2, with final checkpoints at fixed step counts. The existing SFT control uses seed~0 and the same recorded paired-data specification, rehearsal, learning rate, and 256 steps, but omits candidate and exchange losses. It is not relation-free training.

\subsection{Public protocols and metrics}
SpotSound-Bench has 400 queries on 387 audio files; Clotho-Moment has 6,649 queries. We report mIoU and query success at set-IoU thresholds 0.3/0.5 (R1@.3/.5), as percentages. PairAcc@.5 requires both inverse queries to reach correct-target IoU $\geq0.5$. Swap error counts a pair if either answer does not overlap its correct window strictly more than the opposite window; ties are errors. Post-hoc JointPairAcc@.5 additionally requires no Swap error: returning both equal-length windows can pass PairAcc without distinguishing their relations.

UnAV uses the AMR authors' public 100-query release on 77 audio files. SpotSound's Table~2 associates 997 queries with UnAV and 100 with AudioGrounding, whereas the public AMR data associate those sizes in the opposite way. We have not resolved this discrepancy with a paper-specific manifest. Thus UnAV is a qualified reference, not a confirmed sample-matched ranking. Its reported score clips annotations and predictions to decoded duration; without clipping, mIoU is 73.387462\%.

Adaptation uses extra synthetic data. Prior public aggregates informed iterations; this is not a never-inspected confirmatory campaign. We re-audit cached relation predictions with paired cluster bootstrap, while retaining the explicitly labeled historical public-set uncertainty analysis.
