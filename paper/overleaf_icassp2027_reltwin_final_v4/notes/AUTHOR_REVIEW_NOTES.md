# 作者审阅与投稿边界

这份文件不进入四页正文，不是会议录用保证，也不是要求继续扩大实验。论文的目标是让审稿人看清具体问题、对应设计、支持它的结果，以及证据尚未覆盖什么。

## 这次修改的实质

主线从“多个模块提升系统指标”变为“多个真实窗口之间的查询指向绑定”。正确声音不等于正确答案，候选学习明确比较同一音频中真实存在、但不回答当前查询的区间。该问题比极小幅度的边界修正更适合解释本项目已经观察到的行为改善。

正文承认对比学习、反向关系与难负例已有研究；创新范围落在同音频局部答案构造、生成式时间戳监督和行为验证的具体设计。T-CLAP、CompA、CoSTALA、SHINE、Winoground 的相邻贡献均得到引用。没有声称完整文献空间中的“首次”。

JS 的去项对照、SetPO 的等更新步数对照均已完整运行三个种子。它们没有确立独立增量，因此降为增强项分析。这样的取舍减少论文的无证据主张；不把“区间跨零”错误解释为“方法已经被证明等价”。

新增同环境 SFT 检查专门排除历史训练运行环境对主要 SFT/Cand 比较的影响：关系 mIoU +13.97、JointPairAcc +31.25，SpotSound mIoU +1.02，相应来源/音频组 CI 均不跨零。新增统一静音的推理压力测试专门检查与布局相关的时间线索：在改动的 40 段音频上，Cand 相对 SFT 的 JointPairAcc 仍高 20.00 点，来源 CI [2.94,33.33]。统一静音同时大幅帮助 SFT，原始差距缩小，正文也报告这一结果。它们都不是新的自然 benchmark，不能据此删除自然泛化限制。

## 审稿问题与正文应有的回答

| 常见问题 | 本稿的处理 | 剩余边界 |
|---|---|---|
| 是否只是加入合成数据？ | SFT 与 Cand 使用相同配对样本、回放、更新步数和初始权重，新增同环境 seed 0 比较 | 不是全部 SFT 超参空间，也只有一个匹配 SFT 种子 |
| 是否只靠交换正则或额外训练？ | 三种子去 JS、三种子等更新继续训练；不把无独立证据的项包装为主创新 | 历史 RBEE/SetPO 训练运行环境仍不同，不夸大分量归因 |
| 只是让两个输出不一样？ | 同时报告 JointPairAcc 与相同答案修复，不把输出差异等同正确 | 错窗口、边界覆盖不足仍需区分 |
| 模型是否利用合成时间线索？ | 原始波形样本保持不变，只统一布局相关静音模式的预先冻结压力测试 | 只移除这一种线索，不代表去除所有捷径 |
| 数字是否来自不一致的评估？ | 使用统一重评 cohort、逐行核对，旧归档系统单独标注 | 原历史 checkpoint 的字节身份与旧运行条件不能凭名称完全证明 |
| Clotho 的提升是否证明 RelTwin 泛化？ | 明确不是：该结果为 official+边界，只列系统参考 | 独立自然关系泛化仍未验证 |
| 主表是和自己的旧分数比吗？ | 文献部分与 SpotSound Table 3 此前逐项最佳比较；训练归因另表 | 文献总差距不等于我们训练损失的净贡献 |

## 投稿竞争力的诚实判断

这份工作适合定位为明确问题驱动的小型方法与诊断论文，不适合包装成新对比学习原理或通用关系推理突破。最有价值的是同一问题下的数据构造、简单训练和受控行为证据能够相互对应。主要风险仍是方法增量性、单 SFT 种子、合成开发集与自然任务的差距，以及公开数据已参与项目迭代。

写作打磨和小对照能够提高可信度，不能把这些风险完全消除，也不能可靠换算成录用百分比。不因追求更高分而在最后一轮反复试参数。当前受限实验完成后交由作者决定是否投稿。
