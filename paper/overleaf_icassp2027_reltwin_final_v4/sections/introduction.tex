\section{Introduction}
Audio temporal grounding maps a natural-language query to the intervals that answer it. Text-to-audio grounding and audio moment retrieval establish this correspondence beyond fixed event classes~\cite{xu2021grounding,munakata2025amr}. SpotSound equips an audio-language model with interleaved timestamps and training for absent events~\cite{sun2026spotsound}. These advances make it useful to ask a more specific question: when several real windows contain the same event categories, does the model select the window specified by the query's relation?

Consider a recording containing ``dog then bell'' and, later, ``bell then dog.'' Both descriptions are true of the recording. Reversing the query should change the answer window, even though the audio and event vocabulary remain fixed. A timestamp model can fail here without hallucinating a sound: it returns a real occurrence that answers the wrong relation. We call this a \emph{query--window binding error}. The distinction matters because correct event recognition alone does not determine which occurrence to return.

Compositional audio reasoning is not new. T-CLAP already uses concatenated sounds, reversed descriptions, and temporal contrastive training~\cite{yuan2024tclap}; CompA studies event order and attribute binding through paired audio--caption matching~\cite{ghosh2024compa}. CoSTALA additionally develops hierarchical spatio-temporal alignment~\cite{ren2026costala}. In video grounding, SHINE learns from compositional hard negative queries~\cite{cheng2024shine}. Our focus is narrower: \emph{two inverse descriptions are simultaneously true in one recording, but identify different local timestamp answers}. The wrong window is an answer negative, not evidence that the query is globally false. This changes the supervised correspondence from recording--description compatibility to a query-specific choice among real windows.

We introduce RelTwin, a paired training construction for this setting. The same sound excerpts form two opposite-order windows, and each inverse query is scored against both timestamp answers. Correct-answer sequence supervision is augmented with ordinary candidate cross-entropy. The contribution is not a new contrastive loss; it is the construction of locally confusable answers and its implementation in a generative grounding model. Inference remains ordinary timestamp generation, with no added candidate scorer or knowledge of the target windows.

Our evaluation separates three questions: whether candidate supervision adds value beyond SFT on the same relation data; whether more elaborate exchange and setwise objectives are necessary; and how those training effects relate to public grounding performance. We also inspect whether inverse queries receive identical answers and whether both answers are actually correct. This yields a compact training design and a diagnostic account of its benefits and limitations, rather than attributing the complete system's score to every component.
