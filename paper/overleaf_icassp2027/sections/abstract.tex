\begin{abstract}
Finer acoustic evidence does not always justify changing an existing temporal prediction. We present a selective boundary-refinement extension to NOVA for audio temporal grounding. A lightweight utility model uses frozen occupancy and boundary features to estimate the set intersection-over-union gain of local edits. Constrained dynamic programming selects compatible edits while retaining the original prediction as an explicit action. An edit is accepted only when a lower bootstrap utility quantile exceeds a fixed margin, with event-duration-dependent displacement limits. The complete system obtains 59.39\% and 86.86\% mIoU on SpotSound-Bench and Clotho-Moment, exceeding the corresponding best entries in the SpotSound main table by 1.49 and 1.26 percentage points. We report these as system-level comparisons, alongside metric-specific discussion and protocol-qualified transfer results. The formulation connects boundary proposals with the decision of whether an existing answer should be revised.
\end{abstract}
