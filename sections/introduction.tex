\section{Introduction}
Audio temporal grounding maps a query to event intervals~\cite{xu2021grounding,munakata2025amr}. In a recording containing both ``dog then rooster'' and ``rooster then dog,'' the descriptions refer to different windows. Recognizing both categories establishes presence; answering the query requires selecting the requested order. Returning the same real window for both queries is a \emph{query--window binding error}. Sequence supervision rewards each correct timestamp answer without explicitly contrasting it with another acoustically supported window under the same query.

RelTwin (Fig.~\ref{fig:pair}) makes this competition explicit through \emph{locally valid timestamp contrasts}. Shared excerpts form opposite-order windows in one recording. Both windows have real acoustic support, while their correctness as answers depends on the query. Reversing the query exchanges their target assignments without changing the recording. RelTwin scores both timestamp answers under each query and trains the preference for the requested occurrence.

RelTwin uses the grounding model's own timestamp-answer scores. Candidate supervision establishes the correct preference, and query-exchange consistency couples predictions after exchanging candidate labels. Set-level preference optimization then extends the comparison to coverage, event count, and boundaries. Inference remains direct timestamp generation.

We make three contributions. First, we characterize query--window binding errors when inverse relations coexist. Second, we formulate relation-specific grounding as competition between locally valid timestamp answers whose target assignments exchange with the query. Third, evaluations across backbones and benchmarks establish the adaptation benefit, while matched comparisons and timing intervention examine the query-binding mechanism.
