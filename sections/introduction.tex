\section{Introduction}
Audio temporal grounding maps a query to event intervals~\cite{xu2021grounding,munakata2025amr}. In a recording containing both ``dog then rooster'' and ``rooster then dog,'' the descriptions refer to different windows. Recognizing the categories establishes presence; answering the query requires selecting the requested order. Returning the same real window for both queries is a \emph{query--occurrence binding error}: the wrong local occurrence is selected.

We propose NOVA, combining candidate learning for occurrence selection, audio verification for acoustic support, and refinement for boundary alignment. Our core training contribution is RelTwin (Fig.~\ref{fig:pair}), which introduces \emph{locally valid timestamp contrasts}. Shared excerpts form opposite-order windows with real acoustic support; the query determines which window answers it. Sequence supervision rewards correct answers individually, while candidate supervision compares both answers under each query. The trained generator directly outputs timestamps.

We formulate query--occurrence binding as a choice between locally valid timestamp answers. NOVA is evaluated on SpotSound, Clotho-Moment, and UnAV; matched comparisons, inverse queries, and timing intervention examine RelTwin's training effect.
