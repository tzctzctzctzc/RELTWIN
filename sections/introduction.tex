\section{Introduction}
Audio temporal grounding maps a query to event intervals~\cite{xu2021grounding,munakata2025amr}. When sounds recur, recognizing their categories does not determine which occurrence answers the query. In a recording containing both ``dog then rooster'' and ``rooster then dog,'' the descriptions select different windows. Returning the same real window for both is a \emph{query--window binding error}. Sequence supervision rewards each correct timestamp answer without explicitly contrasting it with another acoustically supported window under the same query.

RelTwin (Fig.~\ref{fig:pair}) makes this competition explicit through \emph{locally valid timestamp contrasts}. Shared excerpts form opposite-order windows in one recording. Both have real acoustic support, but reversing the query exchanges their target assignments. The competing answer is the correct answer to the inverse query.

RelTwin trains the model's timestamp-answer scores to favor the query-consistent window and couples the preferences under query reversal. The same competition extends to interval sets with different coverage, event counts, and boundaries. This answer-level formulation adapts SpotSound-A and TimeAudio while preserving direct generation at inference.

Evaluations on three benchmarks show localization gains for both backbones. Matched candidate-supervision experiments link answer competition to relation selection: identical answers to inverse queries fall from 37 to 1 out of 160 pairs, and the binding advantage persists when silence timing changes.

Accordingly, we evaluate the method at two levels: public benchmark scores test transfer to standard grounding, while inverse-query pairs test whether the model selects the requested occurrence. Timing intervention provides a controlled test of positional shortcuts.
