\section{Introduction}
Audio temporal grounding maps a query to event intervals~\cite{xu2021grounding,munakata2025amr}. In a recording containing both ``dog then rooster'' and ``rooster then dog,'' the descriptions refer to different windows. Recognizing the categories establishes presence; answering the query requires selecting the requested order. Returning the same real window for both queries is a \emph{query--window binding error}. We target this distinction between event detection and query-specific localization.

NOVA combines candidate learning for occurrence selection, audio verification for acoustic support, and refinement for boundary alignment. RelTwin (Fig.~\ref{fig:pair}) trains query--window binding through \emph{locally valid timestamp contrasts}. Shared excerpts form opposite-order windows with real acoustic support; the query determines which window answers it. Sequence supervision rewards correct answers individually, while candidate supervision compares both answers under each query. The trained generator directly outputs timestamps.

Our contributions are the characterization of query--window binding errors, locally valid timestamp supervision for relation selection, and empirical improvements in audio grounding. We report NOVA results on SpotSound, Clotho-Moment, and UnAV, then examine RelTwin through matched training, inverse-query diagnosis, and timing intervention.
