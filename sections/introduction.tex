\section{Introduction}
Audio temporal grounding takes a recording and a text query and returns the time intervals containing the requested events~\cite{xu2021grounding,munakata2025amr}. When sounds recur, recognizing their categories does not determine which occurrence answers the query. A recording can contain both ``dog then rooster'' and ``rooster then dog.'' These queries should select different windows. Returning the same window for both is a \emph{query--window binding error}: the model locates real sounds but selects the wrong event sequence for one query.

These advances motivate a complementary question: how should a model choose between two windows that both contain the queried sounds? Sequence supervision rewards each correct timestamp answer individually, without explicitly comparing it against another window under the same query. RelTwin adds that comparison at the level of complete answers. We call these \emph{locally valid timestamp contrasts}: each window contains a real event sequence, and the competing answer becomes correct when the query is reversed.

RelTwin (Fig.~\ref{fig:pair}) constructs opposite-order windows from shared sound excerpts. Holding the recording fixed, inverse queries exchange the correct window. The model learns to favor the matching answer and to switch its preference with the query. A second training stage compares interval sets with different coverage, event counts, and boundaries. Both stages use the grounder's own timestamp-answer scores, enabling adaptation of SpotSound-A and TimeAudio while preserving direct generation without candidate scoring or reranking at inference.

Experiments connect this training signal to localization and query-specific selection. Both backbones improve on three public benchmarks. A matched comparison isolates candidate supervision: identical answers to inverse queries fall from 37 to 1 out of 160 pairs, and jointly correct localization rises by 31.25 percentage points. The advantage persists when silence timing changes while event waveforms and order are preserved. Together, public evaluations and controlled paired tests examine standard grounding performance and the ability to select the occurrence requested by the query.
