\begin{abstract}
Audio temporal grounding locates the time intervals described by a text query. When the same sounds recur in different orders, the model must select the occurrence that matches the query. We introduce RelTwin, a fine-tuning framework that compares complete timestamp answers. Reusing sound excerpts creates two opposite-order windows in one recording; reversing the query exchanges which answer is correct. Training first learns this query-dependent choice, then compares interval sets by coverage, event count, and boundary accuracy. Across SpotSound-Bench, Clotho-Moment, and UnAV-100, RelTwin improves SpotSound-A and TimeAudio by up to 4.23 and 14.48 mIoU points, respectively. In matched candidate-supervision experiments, jointly correct localization of inverse-query pairs improves by 31.25 percentage points over paired supervised fine-tuning. The advantage persists after silence timing changes. RelTwin thus trains query-specific window selection while retaining direct timestamp generation at inference.
\end{abstract}
