\begin{abstract}
Audio temporal grounding must distinguish which event occurrence answers a query, even when opposite event orders coexist in one recording. Models can instead return the same window for inverse queries, revealing a query--window binding error. We introduce RelTwin, an add-on fine-tuning method that constructs opposite-order windows from shared audio excerpts and contrasts their timestamp answers under each query. Both windows have acoustic support; the requested order determines the correct answer. This answer-level competition complements sequence supervision and preserves direct timestamp generation at inference. Applied to SpotSound-A, RelTwin reaches 59.43, 86.68, and 74.03 mIoU on SpotSound-Bench, Clotho-Moment, and UnAV-100, respectively. Against matched paired SFT, it improves joint localization by 31.25 points on synthetic relation-development data and SpotSound mIoU by 1.02 points. The binding advantage persists under timing intervention, supporting explicit supervision of which occurrence answers the query.
\end{abstract}
