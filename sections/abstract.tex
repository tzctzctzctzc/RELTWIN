\begin{abstract}
Audio temporal grounding must distinguish which event occurrence answers a query, even when opposite event orders coexist in one recording. Models can instead return the same window for inverse queries, revealing a query--window binding error. We introduce RelTwin, which constructs opposite-order windows from shared audio excerpts and contrasts their timestamp answers under each query. Both windows have real acoustic support; the requested order determines the correct answer. This explicit answer-level competition complements sequence supervision and preserves direct timestamp generation at inference. Compared with paired SFT, RelTwin improves joint localization by 31.25 points on the synthetic relation-development set and retains an advantage under timing intervention. Across three training seeds, it averages 59.16 mIoU on SpotSound-Bench, surpassing the prior main-table best by 1.26 points.
\end{abstract}
