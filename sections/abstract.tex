\begin{abstract}
Audio temporal grounding can return the same window for inverse queries that require different intervals. Both relations may occur in one recording, so event presence alone cannot resolve this query--window binding error. Sequence supervision rewards correct timestamp answers without explicitly contrasting them with competing windows. RelTwin constructs opposite-order windows from shared excerpts in one recording and contrasts their timestamp answers under each query: each window is acoustically valid, but only one matches the queried order. Inference retains direct timestamp generation. In a matched seed-0 comparison with paired SFT, RelTwin improves joint localization by 31.25 points on synthetic relation-development data and SpotSound-Bench mIoU by 1.02 points. A 20.00-point joint-localization advantage remains on timing-modified recordings. Across three seeds, RelTwin achieves 59.16 SpotSound mIoU, exceeding the cited prior main-table best by 1.26 points.
\end{abstract}
